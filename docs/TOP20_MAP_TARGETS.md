# Top-20 per-map target analysis

Aggregated from downloaded ranked summaries of the current top-20 teams (matches/top20-scout). Each map lists measured top-20 behaviour plus ten target points. Points marked [measured] come from the downloaded games; [hypothesis] marks proposals derived from those measurements and map knowledge — none are validated gameplay yet.

Sample: 1869 team-games across 70 maps. Global averages: kills 7.3, tribute mean 47.2, carry share 0.47, farm spread 19.1 tiles.
